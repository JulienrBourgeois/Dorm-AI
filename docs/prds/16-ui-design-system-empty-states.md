# PRD-16: UI Consistency, Design System, and Empty States

## Goal
Deliver a coherent role-based UI language across admin, inspector, and tenant experiences.

## Source alignment
- Master PRD sections: 7.1-7.5, 8.6, 8.7.

## Scope
- Shared design primitives: typography, spacing, form controls, status chips, cards, tables.
- Role-specific shell behaviors with common interaction patterns.
- Defined empty states for admin, tenant, inspector.
- Browser compatibility validations for Chrome/Safari/Edge/Firefox.

## UX quality bar
- Navigation consistency across roles.
- Mobile-friendly tenant and inspector experiences.
- Clear status semantics for inspection lifecycle.

## Acceptance criteria
- Shared components are reused across key screens.
- Empty states provide meaningful next actions.
- UI remains functional across target browsers.
- Accessibility basics (labels, focus, contrast) meet MVP standard.
