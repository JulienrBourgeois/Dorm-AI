# PRD-08: Inspector Workflow and Inspection Execution

## Goal
Provide inspectors with a fast, reliable checklist execution flow from start to submission.

## Source alignment
- Master PRD sections: 6.5.1-6.5.6, 11.5.
- Functional requirements: FR-20 through FR-25.

## Scope
- Inspector home, inbox, inspections list.
- Start inspection runner with sectioned checklist.
- Notes, damage flags, condition statuses, save progress.
- Review and submit page.

## UX priorities
- Mobile-friendly action-first UI.
- Progress indicators and unsaved-change protection.
- Low-friction capture for photos and notes.

## Acceptance criteria
- Inspector can start only assigned inspections.
- Progress persists across interruptions.
- Submission validates required checklist completion.
- Submitted inspection becomes read-only except permitted admin edits.
