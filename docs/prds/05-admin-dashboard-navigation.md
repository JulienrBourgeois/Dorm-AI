# PRD-05: Admin Dashboard and Navigation Shell

## Goal
Create a high-utility admin shell that supports day-to-day operational control.

## Source alignment
- Master PRD sections: 5.3, 6.3.1, 6.3.2, 7.2.

## Scope
- Admin root and organization selector.
- Admin home dashboard cards, upcoming inspections, recent activity.
- Persistent navigation, profile menu, notification entry points.
- Empty-state onboarding checklist.

## UX requirements
- Fast context switch between organizations for multi-membership admins.
- Stable information architecture with predictable nav labels.
- Responsive behavior with desktop-first optimization.

## Acceptance criteria
- Admin can select an organization and land on scoped dashboard data.
- Core KPI cards render from live system data.
- Empty-state experiences guide setup actions.
- Navigation remains consistent across all admin pages.
