# Dorm AI Mini-PRD Pack

This folder decomposes `docs/MASTER-PRD.pdf` into implementation-ready mini-PRDs you can execute from first commit to production deployment.

## How to use this pack

1. Start with `00-alignment-repository-inventory-and-gaps.md` so existing code, routes, and the master PRD stay in sync.
2. Then follow `00-implementation-roadmap.md` and build each PRD in dependency order.
3. Treat each PRD as a shippable milestone with its own acceptance criteria.
4. For post-MVP work, use `19-post-mvp-backlog.md`.
