# PRD-06: Admin User Management (Tenants and Inspectors)

## Goal
Enable admins to fully manage tenant and inspector lifecycle within each university.

## Source alignment
- Master PRD sections: 6.3.3-6.3.6, 11.2, 12.1, 12.6.
- Functional requirements: FR-7 through FR-11.

## Scope
- Tenants list and detail pages.
- Inspectors list and detail pages.
- Invite flow, status changes, and deactivation/reactivation.
- Assignment surfaces for room/inspection linkage.

## Required actions
- Create invite for tenant or inspector.
- Update profile metadata and account status.
- View assigned inspections and history.

## Acceptance criteria
- Admin can invite users and trigger invitation email.
- Admin can activate/deactivate accounts.
- Detail pages show key relationships (room, inspections, role).
- Deactivated users lose access immediately.
